VIER BESTANDEN
==============

1. scripts/odds_api_ophalen.py    NIEUW — odds via the-odds-api.com
2. scripts/dashboard.py           cijfers van DIT seizoen erbij
3. scripts/dashboard_template.html schakelaar dit / vorig seizoen
4. .github/workflows/ververs.yml  roept de odds-API aan, 2x per dag

Nummer 1 t/m 3 kun je slepen. Nummer 4 moet je weer BEWERKEN via:
https://github.com/justinspiration/Fpl-cockpit/edit/main/.github/workflows/ververs.yml

EERST DIT: DE API-SLEUTEL
-------------------------
1. Ga naar https://the-odds-api.com en vraag een gratis sleutel aan
   (500 credits per maand; wij gebruiken er 60)
2. GitHub -> Settings -> Secrets and variables -> Actions -> New repository secret
   Naam  : ODDS_API_KEY
   Waarde: je sleutel

Zet hem NIET in een bestand. De repository is publiek.

Zonder sleutel slaat het script zichzelf netjes over en probeert het alsnog de
oude scraper. Het dashboard werkt dan gewoon, alleen zonder marktkennis.
